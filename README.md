# SmartGUIDE

Webanwendung, die Forschungsinformationen einer Universität bündelt: Personen, Publikationen, Projekte, Förderungen und Patente.
Sie hilft Mitarbeitenden im Technologietransfer, schnell passende Expertinnen, Experten und Kooperationspartner zu finden.
Die Daten stammen aus offenen Quellen (OpenAlex, DFG, EU-CORDIS, EPO, USPTO) und werden mit KI-Methoden durchsuchbar gemacht.

**Kontext:** Teamprojekt an der Universität Duisburg-Essen (ca. 15 Beteiligte, März–September 2026), agil in Sprints mit Pull Requests und Code-Reviews.

**Technologien:** Python, FastAPI, Angular, TypeScript, Elasticsearch, Sentence Transformers, LLM-Anbindung, Docker

## Meine Rolle

Verantwortlich für den Bereich **Patente** und die **Förder** (Full-Stack, Schwerpunkt Frontend):

- Patent-Modul in Backend und Frontend aufgebaut: Suche, Filter, Paginierung und Detailansicht
- Stichwortsuche für Patente mit hervorgehobenen Treffern und Filtern (z. B. EPO/USPTO, Jahres-Slider)
- Tab „Förderungen“ auf der Personenseite entwickelt: Filter, Statistiken, Paginierung
- Wiederverwendbare Tabellen- und Filterkomponenten für ein einheitliches Design gebaut
- Unit-Tests für das Patent-Backend geschrieben
